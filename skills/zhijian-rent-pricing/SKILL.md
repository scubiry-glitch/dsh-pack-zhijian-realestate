# 租金定价评估 v2

本技能属于 zhijian-realestate 领域包。只用于具体住宅或公寓的月租决策。城市租金综述不套用此模板。本技能独立运行，不叠选通用报告工艺。三段任务图和数据字段见 [租金定价数据模板](../../references/rent-pricing-data-v2.md)。

## 一次取证

先问会改变报价的标的条件：整租或合租、建筑或套内面积、户型、装修、楼层朝向、家具、权属和出租权限、租期、空置成本与业主偏好。未知项如实标注。保存真实工具回执、查询式、时间、TopK/总召回、去重键、剔除理由和有效 n。挂牌、成交、平台估计分开；零召回不等于零供给。工具确定性失败后记录缺口，不给另一成员重复碰相同通道。

**取数闭环。** 先消歧小区，再按已核实的户型、整租方式和区域查询。逐项比对工具回执中的“实际命中条件”和查询文字；文字写了“普租”“面积”却未被服务端命中时，须逐行按返回字段筛选，不能声称服务端已过滤。若总召回大于单次展示上限 TopK，优先用服务端确实命中的、覆盖全价格域的租金分段补取；逐段保存回执、查询时点和实际命中条件，按房源 ID 去重并比较并集 n 与同口径总召回。区间端点重叠时显式去重。分段仍被截断则继续细分；分段不可用、总数不一致或返回字段不足时只能报告可见样本与截断风险，不得称取齐或据此报全样本分位。多次查询不是严格同一时点快照。价格及样本筛选先完成，再进入测算。

## 一次测算

用同产品同区域同时间的可比样本作主估计；单位面积法若共用样本，只能校验算术，不能当独立证据。替代品只作边界，无法可靠换算就不折为目标房点估计。挂牌建议、目标成交带、业主底线是三个不同决策量，分别写性质、条件、来源和算式；缺少成交证据则成交带为推断，缺少成本和偏好则不报硬底。统计显著性弱时只陈述观测，不能把相关性写成因果解释。

作者填写 t2-pricing-data.json，按模板字段给出结论句、条件、三档、可比明细、三种固定依据、逐步计算表、社区近 12 个月租金序列、行动与缺口。三种依据为同质可比主估计、单位面积交叉验证、替代品边界校验；每项写状态、发现、算式和证据，缺数据则写明未计算。有数值的结论必须有输入→算式→结果→证据的逐步复算记录。社区跨户型趋势只作背景，不能替代目标产品可比样本；序列不可得时展示缺口，不造图。独立评审复算承重数字，核来源和产品身份；阻断项由作者在原任务修复并重审，不另设“审计→修订→复审”三节点。

## 固定模板渲染

从已审数据运行本包 scripts/render-rent-pricing.py，生成同源 Markdown、HTML、PDF 和 craft-evidence.json。HTML 用 [页面骨架 v2](../../references/components/rent-pricing-shell-v2.html)，样本图和 12 个月趋势图由数据自动绘制；无数据显示缺口。PDF 由脚本从该 HTML 生成，不带浏览器路径页眉页脚。禁止改用通用 Markdown 转 HTML、复制旧报告数字或把图稿规格文字当成成图。核对单标题、价格卡、可比明细、计算明细、趋势、来源、手机与 A4；机器只查模板绑定和基本版式，业务数字仍由独立评审判断。

历史报告的形成过程见 [原始会话复盘](../../references/rent-pricing-process-review-v1.md)，只继承“结论先行、适用条件、明细可查、图说明决策”的方法，不继承样本与价格。
