# 租金定价评估 v3

本技能属于 zhijian-realestate 领域包。只用于具体住宅或公寓的月租决策。城市租金综述不套用此模板。本技能独立运行，不叠选通用报告工艺。既有三段任务图与 v2 数据字段见 [租金定价数据模板](../../references/rent-pricing-data-v2.md)；详细场景的扩展字段见 [v3 字段规则](../../references/rent-pricing-data-v3.md)。详细场景使用 `zhijian-rent-pricing-detailed`，旧场景继续使用 v2 数据契约。

## 一次取证

详细场景开始前先读 [取数说明与停走规则](../../references/rent-pricing-collection-runbook.md)。它给出一次探针、对象消歧、实际过滤核验、TopK 分段、趋势三级回退和证据包的停走条件。

先问会改变报价的标的条件：整租或合租、建筑或套内面积、户型、装修、楼层朝向、家具、权属和出租权限、租期、空置成本与业主偏好。未知项如实标注。保存真实工具回执、查询式、时间、TopK/总召回、去重键、剔除理由和有效 n。挂牌、成交、平台估计分开；零召回不等于零供给。工具确定性失败后记录缺口，不给另一成员重复碰相同通道。

**取数闭环。** 先消歧小区，再按已核实的户型、整租方式和区域查询。逐项比对工具回执中的“实际命中条件”和查询文字；文字写了“普租”“面积”却未被服务端命中时，须逐行按返回字段筛选，不能声称服务端已过滤。若总召回大于单次展示上限 TopK，优先用服务端确实命中的、覆盖全价格域的租金分段补取；逐段保存回执、查询时点和实际命中条件，按房源 ID 去重并比较并集 n 与同口径总召回。区间端点重叠时显式去重。分段仍被截断则继续细分；分段不可用、总数不一致或返回字段不足时只能报告可见样本与截断风险，不得称取齐或据此报全样本分位。多次查询不是严格同一时点快照。价格及样本筛选先完成，再进入测算。

**租金趋势溯源。** 旧海兴雅苑案例的 12 个月曲线来自政研通 `地理搜索 → 社区 geo_id → 地理数据包 rentIdx`，当时贝壳 `rent market` 已返回 `Unknown tool`。详细场景按目标小区→所属商圈→同城城市级逐级查询；每一级先取得真实地理 ID，再核指标键、单位、统计总体、连续月份、最新期和原始 JSON 回执。目标层级不可得才降级，选中一个可用层级后停止；所有失败尝试及原因留档。图题必须写实际层级，商圈或城市级只作市场背景，不能改名为社区趋势或用于目标户型点估价。滞后序列保留真实月份并明示观察期与滞后月数，不插值成报告当月。选中层级后将同一指标的完整月序列保存在 `trend.historyMonths[]`，展示末 12 期放 `trend.months[]`；四项百分比从原始期值计算，分别为波幅、最新月同比、年内变化和滚动 12 个月均值同比。缺少比较期时逐项注明月份并保持待计算，不借其他层级补数。三级均不可得则展示缺口。贝壳行情失败与政研通各层覆盖是不同的可用性判断。

## 一次测算

用同产品同区域同时间的可比样本作主估计；单位面积法若共用样本，只能校验算术，不能当独立证据。替代品只作边界，无法可靠换算就不折为目标房点估计。挂牌建议、目标成交带、**底价（市场测算硬底）**、**业主确认最低价**分别写性质、条件、来源和算式；缺少成交证据则成交带为推断，市场边界有充分证据时可以测算，但业主未确认最低价时保持待确认，不能称市场测算硬底为业主同意的底线。三档有值时共用一条月租横轴，三段让价百分比统一以挂牌价为分母。统计显著性弱时只陈述观测，不能把相关性写成因果解释。

详细场景作者填写 v3 数据文件，保留结论句、互斥产品案、每案价格、查询审计、分池统计、逐条可比、三种固定依据、逐步计算、趋势降级回执、空置经济性、让价阶梯、合同条款和缺口。每种依据写状态、发现、算式和证据；有数值的结论必须有输入→算式→结果→证据的逐步复算记录。价格分布和近 12 个月趋势各按其真实样本与层级生成；没有数据时展示缺口，不造图。独立评审复算承重数字，核来源、产品身份和样本行数；阻断项由作者在原任务修复并重审，不另设“审计→修订→复审”三节点。

## 固定模板渲染

现有 v2 场景继续由 `scripts/render-rent-pricing.py` 从已审数据生成同源 Markdown、HTML、PDF 和 craft-evidence.json。详细 v3 场景由 `scripts/render-rent-pricing-detailed.py` 读取 `status=reviewed` 的单份 v3 JSON，生成同源 Markdown、HTML、PDF 与哈希台账；命令参数为 `--data --md --html --pdf --ledger`。八章中的分案、四价格状态、共用月租横轴、三段价差、三依据区间、计算链、查询审计、逐条可比、实际层级趋势、四项趋势百分比、让价阶梯与合同条款均从该 JSON 生成。价格刻度、依据区间、样本分布及趋势图只在数据足够时绘制，否则显示缺口。PDF 从同一 HTML 生成。禁止复制旧报告数字或把图稿规格文字当成成图。核对单标题、价格卡、可比明细、计算明细、趋势、来源、手机与 A4；机器只查模板绑定和基本版式，业务数字仍由独立评审判断。

历史报告的形成过程见 [原始会话复盘](../../references/rent-pricing-process-review-v1.md)，只继承“结论先行、适用条件、明细可查、图说明决策”的方法，不继承样本与价格。
