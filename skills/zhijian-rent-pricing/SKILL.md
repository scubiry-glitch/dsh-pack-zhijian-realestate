# 租金定价评估

本技能属于 `zhijian-realestate` 领域包。面向房东、租赁运营者对**具体标的**的月租挂牌与调价决策；城市租金走势综述和旅居市场研究不直接套用。选择本技能时同时选择同包 `zhijian-report-craft`。本技能自带 HTML/PDF 页面骨架和视觉复核约定，不与同包通用渲染/V5 工艺叠选。Host 冻结并下发本次所选材料，不能从全局同名文件替换。

## 开始前冻结决策契约

确认用途与读者、要决定的挂牌/成交/底线、标的形态、数据来源与口径、取数时段和交付形式。只补问会改变定价的缺项，记录用户明确指定的工具与专家。启动团队前核对预设专家及渲染角色在当前环境可用；不可用时明确回退到可用角色，并保存原因。用户要求指定 CLI 时，留存真实调用回执；CLI 不可用要报告缺口，不以另一来源冒充。

## 先核标的，再报价格

记录地址与小区、产权/出租权限、独立入户和厨卫、水电计量、面积口径、户型、楼层、朝向、装修家具、租期和空置/成本约束。未核实字段标“待确认”。整租、合租单间、服务式公寓和短租是不同产品；若关键形态不明，先给条件分案，不把异类租金平均。没有可比样本时，降低精度并提出补采路径，不编造置信区间。

## 证据到价格

先用同产品、同时段、同区域的样本形成主估计；记录逐次查询、TopK 截断、去重和剔除，保留原始明细。挂牌是供给侧要价，成交是实际成交，分别标注；只有挂牌时，建议成交带须写为**推断**。单位面积租金可交叉验证，但只在面积口径一致且样本足够同质时使用。替代产品用于检查价格边界，除非有独立且可靠的换算依据，不折为同一标的的点估计。三路证据相冲突时查产品、位置、时间和样本偏差，不能机械取交集。

将原始接口回执及其时间、查询式、返回上限、原始行数、有效行数、去重键、剔除理由汇入一份证据包后再派给各视角。某种房型零召回时，可用租售户型、单套详情和替代检索交叉核验产品形态；零召回本身不能证明不存在。统计区间下沿须有明确分位或筛选规则，均值不是下沿；低拟合关系只可用于反证，不能拿系数点预测。可比法与面积法若共用样本，应说明相关性，不称为完全独立的两份证据。

把主估计转成三类**决策量**：挂牌价（含议价空间）、目标成交带（对应预期去化时间）、底价（根据持有成本、空置损益和业主偏好）。每个数字列输入、算式、单位、基准日、来源和性质：观测 / 计算 / 情景 / 建议。没有成本和偏好时不能声称“硬底”。比较“立即降价出租”与“等待更高租金”时，固定比较期并写出空置天数、合同期、可成交租金和成本；让价节奏随真实询盘与竞品变化更新。

## 成稿与图

按 [租金定价报告模板](../../references/rent-pricing-report-template-v1.md) 写作；模板给的是核验栏位和表达接口，章节可因证据增删。图稿先写**要读者看懂的判断**，再选关系和图型：产品形态分叉、同质样本分布与价格档位、证据冲突/边界、空置与让价阈值。图内区分样本挂牌、成交、模型测算和建议价，标明单位与时点；无可比序列不造趋势图。成品可参考 [页面骨架](../../references/components/rent-pricing-shell-v1.html)，但不得复制其中占位符为事实。

独立复核者须重算承重数字、TopK/去重池和每条决定价格的来源，挑战最强反例；阻断项由作者修订并重审。审计通过后冻结一份 Markdown 基线，再从它生成 HTML/PDF。逐件核对版本标签、承重数字、页图及 SHA256，并检查宽/窄屏及 A4 的标签遮挡、单位混用、图文差异。机器格式检查和作者自评不能替代独立复核。
