# 写作与章节结构

总体顺序：卷首速览 → 总论提出核心问题与判断 → 分析章节 → 总结回扣问题、边界和行动 → 来源披露。封面/日期/版本是元信息，可以出现于封面、封底与来源区；正文不堆叠协作过程。没有可靠数字时，速览可写有依据的条件判断和待补项，不能为卡片或金句造数。

每个真实分析章（包括行动方案、敏感性等分论）有五件实质内容：
1. 一句话定位：本章可检验的中心判断，不是标题重复。
2. 角色/方案对照：相关主体的职责、选择或前后差异。非政策主题可用方案与约束对照，不虚构“新旧政策”。
3. 依据：明确来源、事实、用户给定条件或待验证假设。不是所有章都必须伪造条款号。
4. 推论与数据：由依据说明因果、参数与结果；数值缺失时明确条件化，并给出补数后如何改变判断。定性推论可以存在，不能伪装成已测量数值。
5. 机会与风险：分别具名写出机会与风险，以及成立条件/失效信号。两者不能合成一个含混标签。

实际 MD 的 h2 分析章逐一映射到 ledger。卷首、摘要、总论、总结、来源、附录、观察清单、封面封底属于元信息/配套区，不借重命名把缺失分析章藏进例外。每件须有针对本章的论证或事实；空容器、固定套话、只出现关键词均不证明实质完整。独立审核负责逐章判断内容适用性。

重要术语首次出现解释；结论区保留边界、未决问题、行动条件和收束句。正文缺项先补到 MD 单源，再重出 HTML/PDF。HTML 不得擅自删段落、增加结论或改算式；分页/书签/页脚等版面后处理也必须绑定最终 PDF 新 SHA。
