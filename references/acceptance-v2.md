# 当前字节验收

必需项取 AI 所选技能的冻结声明，完整三格式需内容与渲染组合；仅内容技能不认证视觉/PDF。必需结果只接受 passed；failed/unverified/缺证/过期/摘要不符均不放行，not_applicable 须有冻结范围依据。

|领域|依据与限制|
|---|---|
|材料|同包版本/digest、角色必读 id/SHA、完整正文及本 task/attempt/session 接纳；路径或“已读”不算交付|
|结构|实际 h2 与 ledger 一一对应，五件套实质、开头/来源/收束；DOM/span 仅定位，语义另审|
|计算|来源/单位/基准/参数/结果；Host 复算支持类型，独立审核查遗漏，局部 PASS 非全文数学认证|
|政策|实际官方原文、文号、地域与发布时间/生效时间/研究时点，未知条件化；机器仅核结构定位|
|格式|MD/HTML/PDF正文与最终三 SHA 对应；同一错误复制三次仍错误|
|视觉|本版离线浏览器1280/375、布局/锚点/计算样式 AA 与截图；CSS grep 不替代浏览器/审美|
|PDF|最终文件解析、封面封底、正文 i/N、品牌/大纲及必要页面渲染；合并后重验|
|审核|非作者逐项给 SHA、位置、依据、复算和未决问题，不以全 true 替代|
|交付|同 task/attempt、材料 digest、契约、当前字节检查/审核/整合一致；旧回执/外部复制无通过身份|

局部预检 craft_gate_report.sh/craft_density_check.py 不宣称完整 ALL PASS。Host 收据不可自造；缺依赖记 unverified 与恢复入口。修复预算有限，撤回/重开/换契约不重置。新版全部适用项覆盖并通过才称合格。
