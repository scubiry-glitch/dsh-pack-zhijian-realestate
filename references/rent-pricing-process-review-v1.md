# 海兴雅苑租金报告：可复用流程与追溯边界

本记录由 2026-09-17 的 `haixing-yayuan/rent-pricing.html` 本地成品，以及后来复用它的 `rent-pricing-zhongtiexicheng-v2` 团队任务与提示词归纳。**尚未找到生成海兴雅苑 v8 的原始会话和完整任务图**；不能把后续复用任务写成当时的生成实录。

## 成品和审计线索能证明什么

最终稿先指出小区内检索到的“1 室”实为合租单间，目标 35㎡ 独立整租缺本小区同质可比。因此先问有没有独立厨卫、入户和计量，再分别给互斥 A/B 价格案。三类依据角色清楚：板块/区级可比作主估计，面积租金作交叉，替代产品只校边界。它保留单次 TopK、检索式、样本行数、去重与计算明细；社区混合户型的月度趋势仅判断时点，不冒充目标户型价格。结论分挂牌、目标成交带和底线，并落到调价节奏。

成品标注了“t6 审计 H1–H4 整改”：H1 将错误的“均值下沿”改为 P25；H2/H3 把 TopK 与去重的 19 行构成披露清楚。页面没有逐条说明 H4 的具体审计意见，因此不能据此还原 H4 的处理过程。它还披露一个低拟合回归不采用，以及商水商电与民水民电样本剔除后过少，不用水电类型强行作价格因子。可复用的是**发现不可靠模型后撤回、解释样本口径**，不是这个个案的分位数、价格或交集算法。

## 后续复用任务图与提示词能证明什么

后来中铁西城 v2 的留存任务为：T1 数据核验/补采 → T2 三依据测算 → T3 撰写 → T4 渲染发布。提示词要求每个数字回溯数据文件、保留 TopK/去重口径和待补项，并在渲染时保持图文数字一致。这些是有用的任务依赖与验收点。

后续提示词同时硬编码“八章”“A/B 两案”“三路必齐”“趋势 SVG”“同套视觉组件”。其中 A/B 仅在房型尚待判定或确有两种出租形态时有意义；独立第三路证据未必能取得；没有合适序列不应画趋势。新场景因此将结构设计为条件模块，主估计不足时降低精度、补数或暂缓报价，而不为了模板完成度制造数字与图。

## 图的可取之处与限制

成品用价格层/区间图直观说明挂牌、目标成交和底线，用条件卡区分两种产品，用证据链展示主估计与边界，用趋势折线表达时间变化。图形选择跟随读者决策问题。但原成品的价格轴标签在窄空间有相互挤压风险，且长表格需考虑手机与打印。新模板只保留“观点决定图型”的原则，要求实际截图检查，不复刻像素、配色或历史数字。
