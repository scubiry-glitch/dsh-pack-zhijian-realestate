# 数据纪律与计算基准

事实标来源、日期、单位、范围；派生数字标测算/估算，观点标研判，缺数据标待补。估算给参数和不确定性；区分绝对量/指数/趋势样本，不插值成真实数据。来源冲突披露口径与选择理由。

来源区 Wind、政研通/zyt、贝壳/beike 各自单列实际状态与范围：已采用/仅趋势/待补/未配置/未使用/通道失败等；不为门禁调用无关通道或造状态。空 rows、error 信封、工具退出码与 HTTP 状态分别记录；空系列不是有效数据，也不证明整条通道故障。获准条件分析时写清假设、限制及待补项。

P=R/y 使用同口径净收益；固定 R 时，相对共同基准 y₀ 的变化=y₀/y−1，两端均对 y₀。绝对估值另算：租金倍数写明月/年分母，不额外混乘12。资金平衡列全部用款、自有资金、新贷及既有负债，避免漏减/重计；融资费用列本金、期间利率、期数。下游仍需复算获审上游数据。

按 [台账](evidence-ledger-v2.md) 绑定输入与结论，机器局部 PASS 不涵盖未声明/未支持公式。图表数字来自正文或可追溯原始数据，概念流程标定性示意。

现行政策实际读取官方原文，记 URL、文号、地域、发布/生效日与研究时点并查后续变更。CLI 标题摘要仅为线索；缺原文须写待核实/条件假设及影响，不以常识或旧报告冒充本期核证。
